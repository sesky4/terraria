`Terraria.GameContent.Drawing` 命名空间的类位于同名目录下。`Terraria/` 目录对应根命名空间 `Terraria`。

## 检索建议

- 找某个 ID 的用法：先查 `Terraria.ID/*.cs` 里的常量，再全文搜索常量名。
- 找某项行为：从 `Player`/`NPC`/`Projectile` 的 `Update`/`AI` 入口往下追。
- 想理解“某帧发生了什么”：从 `Terraria/Main.cs` 的 `Update(GameTime)`（第 16943 行）→ `DoUpdate(ref GameTime)`（第 16997 行）→ `DoUpdateInWorld()`（第 17900 行）这条链入手。
